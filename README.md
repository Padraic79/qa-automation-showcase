# QA Test Automation Showcase

A comprehensive test automation framework demonstrating modern QA practices and tools.

## 🚀 Quick Start

1. Clone the repository
2. Install dependencies: `npm install`
3. Install Playwright browsers: `npx playwright install`
4. Run UI tests: `npm run test:ui`
5. Run API tests: `npm run test:api`

## 📊 Reports

- **UI Test Reports**: Available in `reports/playwright-html/`
- **Allure Reports**: Run `npm run allure:serve`
- **API Test Reports**: Available in `reports/`

## 🔧 CI/CD

This project includes GitHub Actions workflows for:

- Automated testing on push/PR
- Cross-browser testing
- Scheduled regression testing
- Report generation and deployment
